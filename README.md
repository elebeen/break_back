# Nutria
## Una aplicación que permite a sus usuarios elegir que consumen en cada comida
La app conecta a usuarios con restaurantes asociados que ofrecen platos saludables, mostrando información detallada como calorías, proteínas, carbohidratos, grasas y otros datos relevantes como sodio o azúcar, permitiendo tomar decisiones informadas antes de comprar.

Nutria no solo funciona como una plataforma de pedidos, sino como una herramienta integral de bienestar. Según el perfil y objetivo del usuario —bajar grasa, ganar masa muscular, mantener peso o cuidar una condición médica— la aplicación recomienda opciones adecuadas y facilita la compra inmediata mediante delivery o recojo en tienda.
